# SafeWalk

## Team Trio

SafeWalk is a React Native mobile application developed with Expo. The application is designed to help users feel safer when walking alone by providing live location tracking, an SOS emergency feature, trusted contacts, destination selection, and walk history.

## Main Features

- User Sign Up and Login
- Google Sign-In
- Apple Sign-In
- Start a Walk
- Select Destination
- Live Location Tracking
- Live Map
- SOS Emergency Feature
- Emergency Contacts
- Add and Delete Contacts
- Walk History
- Account Management
- Firebase Authentication
- Firebase Firestore
- Local Storage with AsyncStorage
